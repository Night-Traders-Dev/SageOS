# Memory Management for SG2002

Memory management on the SG2002 provides the foundation for kernel allocation and application memory isolation.

## Implementation Details
- **Physical Allocator:** A simple buddy allocator or bitmap-based allocator for managing physical page frames (4KB).
- **Early Heap:** A simple bump-pointer allocator for memory requests during early kernel boot (before the general memory manager is fully established).
- **Virtual Memory:** Leverages RISC-V SV39 paging (as documented in `docs/architecture/sg2002_paging.md`).

## Assumptions
- Booted with SV39 paging enabled or ready to be enabled.
- Physical memory regions defined in the Device Tree (DTB).
